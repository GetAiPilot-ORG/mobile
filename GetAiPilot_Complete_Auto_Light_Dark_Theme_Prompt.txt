GETAIPILOT MOBILE — COMPLETE THEME IMPLEMENTATION PROMPT
Premium Dark Theme + Existing Light Theme + Automatic Device/Browser Theme Sync

OBJECTIVE

Implement a complete theme system for the existing GetAiPilot Mobile app with the following behavior:

1. Preserve the app's current LIGHT theme.
2. Upgrade the DARK theme to the premium dark/navy visual style described below.
3. Make SYSTEM theme the default.
4. Automatically follow the device or browser appearance:
   - Device/browser Light Mode → App Light Theme
   - Device/browser Dark Mode → App Dark Theme
5. Update the app immediately when the device/browser changes theme while the app is open.
6. Keep manual Light / Dark / System options.
7. Do NOT change any existing layout, structure, navigation, images, icons, spacing, or application functionality.

THIS IS A THEME-ONLY IMPLEMENTATION.

3. REQUIRED THEME MODES
==================================================

The app must support exactly these modes:

type ThemeMode = 'system' | 'light' | 'dark';

Use:

themeMode = 'system'

as the default for users who have not explicitly selected another preference.

Maintain two concepts:

themeMode:
'system' | 'light' | 'dark'

resolvedTheme:
'light' | 'dark'

Resolve theme like this:

if themeMode === 'system':
    resolvedTheme = current device/browser appearance
else:
    resolvedTheme = themeMode

Then:

isDark = resolvedTheme === 'dark'

The theme colors used by the UI must be based on resolvedTheme.

==================================================
4. SYSTEM MODE BEHAVIOR
==================================================

SYSTEM mode must dynamically follow the device/browser.

When themeMode === 'system':

Device/browser Light:
resolvedTheme = 'light'

Device/browser Dark:
resolvedTheme = 'dark'

If the user changes system appearance while the app is already open:

Light → Dark
App must switch immediately to Dark.

Dark → Light
App must switch immediately to Light.

No refresh.
No reload.
No restart.

==================================================
6. WEB / BROWSER THEME DETECTION
==================================================

For web builds use:

window.matchMedia('(prefers-color-scheme: dark)')

Determine system appearance using:

mediaQuery.matches

true → dark
false → light

Also listen for live browser/OS changes using:

mediaQuery.addEventListener('change', handler)

Use:

addListener/removeListener

only as a compatibility fallback where necessary.

Correctly clean up the listener.

Do NOT require:

window.location.reload()
location.reload()
router.reload()

The React theme context must update live.
